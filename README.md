# Dr. Asher Natural Chiropractic — Static Site

Static HTML snapshot of [drashernaturals.com](https://drashernaturals.com), ready to host anywhere.

## Quick start

- **View locally:** Open `drasher-static/drashernaturals.com/index.html` in a browser.
- **Deploy:** Upload the contents of `drasher-static/drashernaturals.com/` to any static host (Netlify, Vercel, GitHub Pages, or your own server). Set the site root to that folder (e.g. **Publish directory:** `drasher-static/drashernaturals.com` if deploying from this repo).

## What’s in this repo

| Path | Description |
|------|-------------|
| `drasher-static/drashernaturals.com/` | The live site (HTML, CSS, JS, images). Deploy this folder. |
| `drasher-static/drashernaturals.com/FOR-CLIENT.txt` | Client-facing note: what works, what doesn’t, how to open. |
| `HOW-TO-MAKE-IT-WORK.md` | How to reconnect the contact form (e.g. Formspree) and optional search. |
| `drasher-clone-plan.md` | Original clone plan. |
| `urls-to-clone.txt` | List of URLs that were cloned. |
| `screenshots/` | Full-page screenshots of each main page. |

## Making the contact form work

See **HOW-TO-MAKE-IT-WORK.md**. Short version: point the Contact form to [Formspree](https://formspree.io) (or Netlify Forms / mailto).
